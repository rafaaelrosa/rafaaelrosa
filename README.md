### What I've been building

**[Eduzz Membros](https://www.eduzz.com)** — the members area platform I lead.
Consolidated 15 repositories into a monorepo with a coverage gate in CI, ran a five-stage
SQL Server sanitization (38% less index write cost, 52% fewer deadlocks under 20% more
traffic), and drove every queue from Redis to RabbitMQ with end-to-end observability.

**[Deus.iA](https://apps.apple.com/us/app/deus-ia-god-chat-bible-ai/id6761734427)** —
Bible-based conversational assistant, [on iOS](https://apps.apple.com/us/app/deus-ia-god-chat-bible-ai/id6761734427)
and [Android](https://play.google.com/store/apps/details?id=com.deusai.mobile). A RAG backend
grounds every answer in Scripture: Express and TypeScript in hexagonal layers, Supabase with
pgvector for retrieval, OpenAI for generation, on Cloud Run — plus the React Native app.

**[Severino](https://rafaaelrosa.github.io/financial-agent-page/)** — personal finance
assistant that lives in WhatsApp. An OpenAI agent picks the intent through tool calls and
answers in the chat, from text, a voice note transcribed with Whisper, or a photo: a receipt
is read item by item and categorised, a Pix or card proof becomes a single expense.
